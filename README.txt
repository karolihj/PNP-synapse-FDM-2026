MATLAB code for the paper KH Jaeger, and A Tveito, 'Accurate computation of ionic concentrations in the synaptic cleft requires the full Poisson–Nernst–Planck (PNP) equations', 2026.

The script 'run_simulation_PNP.m' can be used to run a PNP simulation and the script 'run_simulation_D.m' can be used to run a pure diffusion (D) model simulation.
